The app shows an older version

  1. Connect to the internet and reopen Geography Gym.
  2. Refresh the browser page once to allow the new service worker to take control.
  3. If installed, close and reopen the installed app after refreshing in the browser.

Sound does not play

Confirm that Answer sounds is enabled in Settings and that the browser or device is not muted. Browsers permit audio after you interact with the page, so answer one question before testing again.

Progress appears to be missing

Progress is stored separately for each browser, browser profile, device, and website address. Open the same browser and app URL used previously.

The install button is missing

Some browsers place installation in their own menu instead of showing an in-app prompt. On iPhone and iPad, use Safari’s Share menu and choose Add to Home Screen.

What to include in feedback

  • Your device, operating system, and browser.
  • The learning path and question that caused the issue.
  • What happened and what you expected.
  • A screenshot when it helps explain the problem.

Please report incorrect facts or ambiguous answers. Geography Gym should explain the world accurately and clearly.
